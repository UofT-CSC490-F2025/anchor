# Anchor

A full-stack ML-powered mobile application to detect and explain fake or AI-generated content on TikTok.

## Structure
- `backend/`: FastAPI backend, ETL, ML models, feedback loop
- `mobile/`: React Native mobile app
- `infra/`: AWS and PostgreSQL setup
- `.github/workflows/`: CI/CD pipelines

## Getting Started
See `backend/README.md` and `mobile/README.md` for setup instructions.
